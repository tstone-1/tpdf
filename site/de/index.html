Ein schneller PDF-Viewer und -Editor für macOS, Windows und Linux

Kostenlos und quelloffen. tpdf durchsucht gescannte Seiten, entfernt, was ein schwarzer Kasten übrig lässt, und prüft, dass es weg ist, und signiert mit Ihrem eigenen Zertifikat. Ohne Konto und ohne Telemetrie; Ihre Dokumente bleiben auf Ihrem Computer.

Für Mac herunterladenApple Silicon, signiert und notarisiert Für Windows herunterladen64 Bit, ohne Administratorrechte Für Linux herunterladenx86-64, .deb oder AppImage

Auf einem Mac geht auch brew install --cask tstone-1/tpdf/tpdf. Für Intel-Macs, Windows auf ARM und ARM-Linux gibt es keine Version.

Unter Linux nehmen Sie das .deb für Ubuntu 24.04 oder Debian 13 und neuer (sudo apt install ./tpdf_<version>_amd64.deb), sonst das AppImage. tpdf braucht glibc 2.39 oder neuer und startet daher nicht unter Ubuntu 22.04 oder Debian 12. Unter Linux aktualisiert sich tpdf nicht selbst: Installieren Sie das neue Paket, wenn eine Version erscheint. Die Texterkennung braucht das Tesseract des Systems, das das .deb mitinstalliert und das AppImage nicht.

Das Windows-Installationsprogramm ist signiert; als Herausgeber steht dort Open Source Developer Timo Stein. Das Zertifikat ist neu, deshalb kann Windows beim ersten Start „Der Computer wurde durch Windows geschützt“ anzeigen: Wählen Sie Weitere Informationen, prüfen Sie den Herausgeber und dann Trotzdem ausführen.

tpdf erscheint auf Deutsch, wenn das System Deutsch spricht, und duzt zunächst; Sprache: Deutsch (Sie) in der Befehlspalette stellt auf „Sie“ um. This page in English.

Eine gescannte Seite durchsuchen

Ein Scan ist ein Bild der Seite. Die Suche findet darin nichts, nicht einmal die Rechnungsnummer, die Sie vor sich sehen. tpdf liest die Seite auf Ihrem Computer, wenn Sie darum bitten, und danach findet die Suche sie. Probieren Sie es in drei Schritten aus.

  1. Öffnen Sie ein gescanntes PDF. Eines von Ihnen oder diese erfundene Rechnung.
  2. Suchen Sie darin. Drücken Sie Strg+F (⌘F auf einem Mac) und geben Sie RE-2026-0417 ein. In der Suchleiste steht kein Text: gescannte Seiten.
  3. Klicken Sie in der Suchleiste auf Diese Seite erkennen. Jetzt findet die Suche die Nummer zweimal. Die Erkennung läuft auf Ihrem Computer und gilt nur vorübergehend: Das PDF bleibt unverändert, und eine Bearbeitung oder das Verlassen der Seite verwirft sie.

Soll der Text bleiben, schreibt Text erkennen und speichern unter... eine Kopie, in der jede gescannte Seite durchsuchbar ist.

Finden, was ein schwarzer Kasten im PDF übrig ließ, und es entfernen

Die häufigste falsche Schwärzung legt ein schwarzes Rechteck über die Wörter und lässt sie in der Datei, wo jeder sie herauskopieren kann. tpdf listet diese Wörter auf, entfernt sie aus der Datei und prüft die geschriebene Datei; der Rest des Dokuments bleibt Text. Wenn tpdf nicht prüfen kann, sagt es „nicht bestätigt“ und nie, die Datei sei sauber. Zum Ausprobieren gibt es einen erfundenen englischen Brief mit vier schwarzen Kästen.

Ein Dokument signieren und eine erhaltene Signatur prüfen

Signieren Sie mit einem Zertifikat aus dem macOS-Schlüsselbund oder dem Windows-Zertifikatspeicher. Ihr Unterschriftsbild steht auf der Seite, ein Zeitstempeldienst bestätigt die Zeit, und die Signatur sperrt das Dokument, sodass eine spätere Änderung gemeldet wird. Bei einem signierten Dokument sagt tpdf, ob jede Signatur intakt ist, ob Ihr Computer dem Unterzeichner vertraut und was nach dem Signieren hinzukam.

Markieren, ausfüllen und umstellen

Hervorheben, unterstreichen, zeichnen, Textfelder, Stempel und Kommentare hinzufügen. Formulare ausfüllen und Formularfelder anlegen. Seiten drehen, verschieben, löschen, zuschneiden, herauslösen und einfügen; Dokumente zusammenführen oder teilen. Außerdem eine kleinere Kopie speichern und ein Passwort setzen oder entfernen.
